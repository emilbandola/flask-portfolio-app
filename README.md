# Flask Developer Portfolio App

A dynamic personal portfolio web application built with Python and Flask. This project transitions a static HTML/CSS developer card into a server-rendered web application using Jinja2 templating.

## Tech Stack
* **Backend:** Python 3, Flask
* **Frontend:** HTML5, CSS3, Jinja2
* **Tools:** Git, GitHub, Visual Studio Code

## Local Setup & Installation

1. **Clone the repository:**
    ```bash
    git clone https://github.com
    cd flask-portfolio-app
    ```

2. **Install Flask:**
    ```bash
    pip install flask
    ```

3. **Run the application:**
    ```bash
    python app.py
    ```

4. **View in browser:**
    Open `http://127.0.0.1:5000` in your web browser.
